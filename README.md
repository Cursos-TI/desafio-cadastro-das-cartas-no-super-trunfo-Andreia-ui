## Super Trunfo Cidades - Análise de Dados por Categoria | Grupo Boticário

Projeto de estruturação e análise de dados desenvolvido em C - ADS Estácio.

### Sobre o Projeto
Sistema para cadastro e análise de 32 cidades divididas em 8 categorias (Estados A-H) com 4 indicadores: População, Área, PIB e Pontos Turísticos.

### Relevante para Assistente de Categorias (Dados)
- Organização e categorização de dados
- Análise de indicadores de performance (PIB, População)
- Estruturação de base para relatórios e dashboards
- Lógica para comparativo entre categorias

**Tecnologias:** C, Estruturação de Dados, Análise de Indicadores, Lógica de Programação
